# 方法论：三层数据模型与边界

> 本文件是系统的设计依据。它解释了**为什么这个平台不提供「每天跟着国家队买什么」**，
> 以及在此约束下我们到底监控什么、如何标注可信度。

---

## 一、定位：从「跟单系统」改为「分层监控 + 带置信度的概率推断」

原需求是「每天跟着国家队操作 / 监控国家队资金判断是否进场」。经研判，
**这个目标的一半在公开数据下不成立**：

- 官方不逐笔披露国家队交易，盘中没有任何渠道能看到汇金下单；
- ETF 每日只公布总份额与申赎清单，**不公开申购人身份**；
- 保险、公募自营、券商自营、外资、国有资本都可能大额申购宽基 ETF；
- 上市公司十大流通股东 / ETF 持有人是**确权数据**，但滞后 1–2 个季度。

因此平台定位调整为：
> **用国家队资金相关公开信息判断「是否出现托底信号、敢不敢进场、进多少」（择时与仓位），
> 不用它判断「买哪只个股」（选股）。**

系统**不输出**买入/卖出/目标价/荐股措辞，只输出信号状态、置信度与局限说明。

## 二、三层数据模型

| 层级 | 名称 | 时效 | 可归因到主体 | 置信度 | 典型来源 |
|------|------|------|-------------|--------|---------|
| **L1** | 实测（季度确权） | 滞后 1–2 季 | ✅ 是 | high | 上市公司十大流通股东/十大股东、ETF 半年报与年报前十大持有人 |
| **L2** | 估算（T+1） | 盘后 T+1 | ❌ 否 | low | 宽基 ETF 每日**总份额**变动 × 当日净值 |
| **L3** | 代理 / 交叉验证 | T+0 ~ T+1 | ❌ 否 | medium | 央行/汇金/证监会/国资委/国新·诚通公告、互换便利、回购增持再贷款、融资余额、成交额 |

**铁律**

1. L2 永远 `attributable=False`，**不得**表述为「国家队买入 X 亿元」；
2. 基于 L2 的推断置信度上限为 `medium`；
3. 任何信号 `is_confirmed=False` 恒成立；
4. L1 的「名单新进/退出」不等于增减持。

**ETF 份额的正确用法**：份额增加 = 一级市场净申购；份额减少 = 净赎回。
二级市场成交额放大**不改变总份额**，只看放量会误判。
估算公式：`净申购额（亿元） = Σ(份额增量 × 当日净值) / 1e8`。

## 四、术语表

| 术语 | 定义 |
|------|------|
| 净申购额 | ETF 份额增量 × 当日净值（亿元）。仅代表全市场一级市场净申购，无法识别申购人 |
| 名单进出 | 十大股东名单新进/退出，仅代表排名变化，不等于增持/减持 |
| 持股变动 | 经送转股/增发/回购复权调整后的持股数差额；被动变动不计入主动增减持 |
| PIT 时点 | `report_period`（季度标签）、`report_period_end`（期末 ISO 日）、`disclose_date`（实际披露日）、`effective_date`（= 披露日，策略最早可用日） |
| 托底信号 | 三重共振成立时的概率推断，永远 `is_confirmed=False` |
| 政策底 | 稳定市场力量开始加强的位置；**不等于市场底**，历史间隔 40 天至 6 个月 |
| 放量倍数 | 当日成交额 ÷ 前 5 日平均成交额。L3 辅助观测，不改变份额、不可归因 |
| 环比增长率 | (当日成交额 ÷ 前一日 − 1) × 100%；放量 2 倍即 ≥100%，非信号 |
| 量能异动 | 放量倍数达阈值的中性观测状态；`is_signal` 恒 `False` |
| 份额 vs 成交额 | 份额由一级市场申赎决定；成交额为二级市场买卖金额，放量不改变份额 |
| 2026 重点观察 | 588000/159915 的前端高亮标记，源自未确权观点，不参与信号计算、非推荐 |

> 完整术语表（含英文键名说明）以 `src/ntm/layers.py` 的 `GLOSSARY` 与
> `GET /api/methodology` 返回为准。

## 五、信号：三重共振

```
条件① 市场大跌      当日涨跌幅 ≤ -1.5%  或  近 5 日累计 ≤ -4.0%
条件② 宽基份额同步  同步净申购只数 ≥ 3  且  合计净申购额 ≥ 200 亿元
条件③ 官方公告      近 5 日存在增持/稳市类公告（is_supportive=True）

①∧②∧③ → POLICY_BOTTOM_PROBABLE  (confidence=medium)
仅 ②    → INFLOW_ONLY             (confidence=low)   只记「有大额增量资金承接」
仅 ③    → ANNOUNCEMENT_ONLY       (confidence=low)   公告表达意图，额度≠实际买入
其他    → NO_SIGNAL               (confidence=low)
```

阈值可通过环境变量调整（见 `.env.example`）。**三者缺一，绝不标记为国家队进场**。

每条信号附带 `attribution`（无法归因到具体主体）与 `caveat`：
政策底≠市场底、历史间隔 40 天至 6 个月、国家队入场可增强信心但不宜成为抄底理由、
系统不提供个股买卖建议。

### 5.5 量能观察层（辅助，不参与信号）

用户提供的「放量 2 倍」监控诉求，系统实现为**独立的客观观测层**，
见 `src/ntm/momentum.py` 与 `GET /api/etf/momentum`：

| 指标 | 公式 | 层级 |
|---|---|---|
| 环比增量 | 当日成交额 − 前一交易日成交额 | L3 辅助 |
| 环比增长率 | (当日 ÷ 前一日 − 1) × 100%，放量 2 倍即 ≥100% | L3 辅助 |
| 放量倍数 | 当日成交额 ÷ 前 5 日平均成交额 | L3 辅助 |
| 份额变化 | 份额增量 × 净值（`est_net_yi`） | L2 估算 |

**核心口径约束**：ETF 份额只由一级市场申赎决定，二级市场成交额无论多大都不改变
份额。因此：

- 放量 ≠ 份额增加 ≠ 国家队加仓，**不构成信号判据**；
- 量能观测**不进入** `signals.evaluate()`，三重共振条件集合恒为
  `{market_drop, etf_sync, official}`，不存在「第四条件」；
- `summary.is_signal` 恒为 `False`；
- 输出文案只描述「几只放量达标 / 是否伴随份额净增」，不出现任何买卖措辞。

演示数据刻意构造一个「7 只全部放量 2.3–2.8 倍、份额变化接近 0」的反例日，
用于直观验证上述区别。汇总函数会自动指出「仅 N/M 只伴随份额净增，
其余放量并未伴随份额增加，说明成交额放量不能推出申购或加仓」。

### 5.6 参考策略的边界

用户提供的三套监控方案、买卖规则、复盘流程与风险提示，全部**原文存档**于
`docs/REFERENCE_STRATEGY.md`，并逐条标注处置（结构化版本 `src/ntm/reference.py`，
接口 `GET /api/reference/strategy`）。

- **客观数据与流程**（标的池、成交额/环比/放量倍数、复盘三步）→ 已实现；
- **依赖外部账号/商业数据或需额外合规核验**（万得/同花顺技能、上交所份额公告
  确认国家队持仓）→ 保留为参考；
- **买卖点位、分批仓位、择时指令** → 不实现。理由：公开数据无法日频归因到
  国家队，且系统定位不是跟单或荐股系统；「成本比国家队低、卖得比国家队晚」
  隐含可观测国家队成交时点，而该时点无公开日频数据。

系统保留的等价中性能力只有：`spike_count`（放量达标只数）与纯观测描述，
且明确不是信号。588000 / 159915 的「2026 重点观察」仅为未确权观点的高亮标记，
不调整信号权重、不是推荐。

## 六、四条硬性清洗规则

1. **名单进出 ≠ 增减持**：新进名单可能是首次买入，也可能只是排名上升进入前十；
   退出名单可能是减持，也可能是被其他股东挤出前十。二者均标记 `is_actionable=False`。
2. **复权**：`adjusted_prev = prev.shares × factor`；若复权后差额为 0，
   判为「被动变动（复权后无主动增减）」，不计入主动增减持。
3. **口径分离**：十大股东与十大流通股东禁止跨口径比较。
4. **PIT 防前视**：回测只用 `effective_date <= as_of` 的记录；
   信号盘后生成，最早入场时点为**下一交易日收盘**，不用当日收盘价成交。

---

## 七、回测约束

- 基准：同期指数买入持有；
- 考虑交易成本、涨跌停/停牌不可成交（当前 MVP 仅在说明层约束，未做撮合模拟）；
- 输出事件数、胜率、平均前瞻收益、最大回撤；
- **样本量警示**：国家队进场事件在历史上为个位数（2008/2015/2018/2024/2025/2026），
  任何统计结论都极易过拟合；政策底到市场底 40 天至 6 个月不等。

## 八、真实数据源接入核验清单

`NTM_ENABLE_LIVE_ADAPTERS=0` 默认禁用；逐项确认并留档（Wind MCP 已核验项见 8.2）：

- [x] 数据源的**授权与使用条款**：凭据由接入方自行提供并承担授权、版权与频控责任，已留档
- [x] 接口字段含义、更新频率、历史回溯范围：2026-11-10 协议握手 + 真实取数实测，见 8.2
- [x] 只取 **ETF 总份额** 与 **净值**：`validate_dataset` 明确拒绝成交额/资金流顶替 `total_share`
- [ ] 主体账户名的实际披露字符串清单，补全别名映射并补测试
- [ ] 季报/年报披露日抓取：L1 尚未接入，保持空列表并显式标注，不伪造 `disclose_date`
- [ ] 交易日历（节假日、临时休市）：定时表达式仅按周一至周五粗判
- [x] 失败即停、幂等去重、数据质量校验：快照按 `(date, code)` 去重，四层字段闸门 + PIT 前视校验
- [x] 归因边界：所有 L2 输出仍标注「不可归因」，接入真实数据也不改变这一事实

> **重要**：即使接入真实数据，「谁在申购 ETF」依然不可知。真实数据不会让
> `is_confirmed` 变成 True，只会让 L2 估算更准确。

### 8.1 外部数据源核查：Wind Alice Market（2026-11-10）

用户提供的微信推文《重磅：Alice Market个人订阅正式上线！A股行情免费用!》
经核查为 **Wind 商业产品推广**，不是数据源：

| 核查项 | 结论 |
|--------|------|
| 推文是否含接口地址 / 参数 / 返回样例 | **均无** |
| 产品性质 | Wind MCP / Skill / Agent 个人订阅，体验版 49 元/月起 |
| 接入凭据 | `WIND_API_KEY`，需在 `market.windalice.com` 注册后自行生成 |
| 官方安装协议 | `https://aifinmarket.wind.com.cn/skill.md`（安装向导，非接口文档） |
| 免费范围 | 官方表述「A股行情免费」，字段清单以官网为准，推文未列出 |
| MCP server 分类 | stock_data / fund_data / index_data / bond_data / financial_docs / economic_data / analytics_data |
| 是否覆盖 ETF 总份额 | **未证实**，需核对 fund_data 工具契约 |
| 是否覆盖季度十大流通股东 | **未证实**，需核对权限 |

**关键口径**：本平台 L2 需要的是 ETF **每日总份额**（一级市场申赎），
这不属于「行情」范畴；L1 需要季度持有人与真实披露日。因此即使免费行情可用，
也只可能覆盖条件①（指数涨跌幅）与量能观测（成交额），**无法替代 L2/L1**。

另外，WorkBuddy 会话级数据服务返回的是 12 小时临时凭证，属于对话内查询能力，
**不能作为云服务器后台的长期数据源**；服务器端接入必须使用可长期调用、
已完成授权与字段核验的端点。

系统据此把接入层实现为配置驱动：`src/ntm/datasource.py` 定义字段契约与状态，
`src/ntm/adapters/live.py` 在凭据/端点/核验三者齐备前拒绝采集，
失败即报错停止，绝不降级回演示数据。状态可由 `GET /api/datasource` 查看。

### 8.2 Wind MCP 实测核验记录（2026-11-10，已接入）

用户随后提供了带长期 API Key 的 Wind MCP HTTP 端点
`https://mcp.wind.com.cn/vserver_wind_tools/mcp/`。**这与 8.1 所评的
「Alice Market 个人订阅推文」不是同一通道**：一个是产品推广文，一个是可直连的
工具型数据服务。对该端点做了协议握手、工具契约与真实取数核验：

| 核验项 | 实测结论 |
|--------|----------|
| 协议 | stateless Streamable HTTP / JSON-RPC 2.0 / SSE；服务端 `wind-mcp-streamable-http-stateless v1.25.0` |
| 工具暴露方式 | 仅 2 个元工具：`market_search_tools`（检索工具契约）+ `market_call_tool`（取数） |
| 条件① 指数行情 | `get_index_kline` 支持 `begin_date/end_date/period/count`，一次取回区间日 K；实测返回 36 个交易日收盘价与成交额 |
| **L2 ETF 总份额** | `fund_get_size` 提供 `f_unit_floortrading`（场内流通份额，份）、`f_unit_floortradingchange`（当日份额变化，份）、`f_unit_changedate`；7 只标的池全部有值 |
| 历史回溯 | 按 `asOfDate` 逐日调用，实测 11-09 / 11-06 / 10-30 / 09-30 的份额与变化各不相同；非交易日回退到最近交易日，**以返回的份额变动日期为准** |
| 净值与量能 | `fund_get_listed_historical_price` 的 `f_nav_iopv`（IOPV，净值口径）与 `f_dq_amount`（成交额，元） |
| L1 十大流通股东 | **未命中专用明细工具**，保持空列表并标注缺口 |
| L3 官方公告 | `get_company_announcements` 全文检索召回精度不足（实测返回国新中期票据募集说明书），**不用于自动确权** |
| 更新频率 | ETF 份额为**日频（T+1）**，不是逐笔实时；指数快照可为盘中时点 |

**结论修正**：8.1 中「免费行情无法覆盖 L2」的判断对 Alice Market 个人订阅推文
依然成立；但用户提供的这个工具型 MCP 端点**确实覆盖了 L2 日频份额**，因此
L2 已从「缺口」变为「已接入」，L1 / L3 仍是明确缺口。

实现位于 `src/ntm/adapters/wind_mcp.py`：

- 每日快照累积在 `data/wind_history.json`，刷新时只补抓缺失交易日。
  原因是 `db.save_dataset` 为全量替换，若只取当日会清空历史序列、
  导致 5 日跌幅与图表失效。
- 所有数据先经 `datasource.validate_dataset` 校验（拒绝 demo 来源标记、
  未来日期、可归因标记、行情字段顶替份额），通过后才入库。
- 请求失败、字段缺失、解析异常一律抛 `LiveDataError` 停止采集，
  **不降级回演示数据、不写入半份数据**。
- `data/verified_announcements.json` 是 L3 唯一入口，且只接受人工核验记录；
  系统不自动把新闻或公告标为 `is_supportive`，避免伪造确权信号。

## 九、合规与免责

- 凭据（webhook、SMTP）只从环境变量读取，不写入数据库、日志、报告或版本库；
- 默认演示数据为合成数据，页面与 API 强制显示 `is_demo` 警示；
- 所有输出标注「基于公开数据的概率推断，无法确权」；
- 系统不提供个股买卖建议、不构成投资建议或择时建议；
- 使用者需自行判断数据来源的合法合规性并承担决策风险。

## 十、已知限制

| 限制 | 影响 | 后续 |
|------|------|------|
| 演示数据为合成 | 不可用于实盘 | 按第八节接入真实源 |
| 交易日历仅判周末 | 节假日可能生成非交易日 | 接入交易所日历 |
| SQLite 单实例 | 不适合多实例并发写 | 数据量上来后迁 PostgreSQL/TimescaleDB |
| 未做撮合级回测 | 无滑点/涨跌停/停牌模拟 | 引入事件驱动回测框架 |
| 前端 CORS 为 `*` | 生产需收敛 | 部署时改为具体域名 |
| 信号样本极少 | 统计结论不稳定 | 只作参考，不作依据 |
| 成交额为演示合成 | 放量倍数不可用于实盘 | 接入真实成交额后仍只作辅助观测，不升级为信号 |
| 「持仓占比 20–40%」「2026 布局转向」未确权 | 不能写成事实或权重 | 仅作参考观点存档，待 L1 季度披露验证 |
| 未接入万得/同花顺商业数据 | 无申赎明细与自动推送 | 需账号授权与合规核验，见第八节 |

## 十一、数据可得性断点（跨期样本必须分段）

以下两条为**已核实的监管口径变化**，不改变本系统的信号定义，但显著收紧了
L1 / L3 的可归因边界。任何跨越断点的长样本必须分段，禁止把断点前后口径
直接拼接后计算相关系数或累计资金。

| 生效日 | 变化 | 对本项目的硬约束 |
|---|---|---|
| **2024-08-19** | 上交所「上证发〔2024〕106号」调整沪港通/深港通交易信息披露机制：北向收市后仅公布成交总额、总笔数、ETF 成交总额、前十大活跃证券及成交总额；取消每日买入/卖出金额拆分与**每日净买入**；单只标的合计持股改按季度公布。港股通（南向）仍公布买入/卖出金额及笔数 | 「北向资金日频净买入」自该日起**不可得**。任何以之作为 L3 代理的长样本必须分段，或改用其他口径并标注不可比 |
| **2026-05-01** | 证监会《公开募集证券投资基金信息披露内容与格式准则第 2 号—定期报告的内容与格式》（证监会公告〔2026〕5号，2026-03-13 发布）施行，第 31 条只要求披露持有人户数、机构/个人持有占比与相关风险提示，删除旧半年度准则第 29 条「上市基金列示前十名持有人」 | **L1 主来源失效**：ETF 半年报/年报前十大持有人仅 ≤2025 年报可用。按披露账户名归并主体（第三节）的路径在 2026 年后不再有可持续的日频/半年度确权数据 |

结论：公开数据「无法归因到国家队」不只是日频限制，2026 年后连半年度
确权数据的强制披露依据也已消失。核验等级：官方原文已核实
（上交所官网、证监会准则；2026-11-11 经 WebSearch 复核）。

**口径边界（重要，防止误读）**：

- 2024-08-19 是**北向日频口径**断点，只影响以北向作协变量/对照的设定；
  「港股通（南向）持股数量仍日频」与北向断点不冲突。
- 2026-05-01 是 **L1 确权通道**断点，**不影响 L2 每日总份额**：份额来自交易所/基金公司
  盘后申赎，口径仍然连续。S3 分段（2026 年后）的含义是「事后 L1 确权校验不可用」，
  不是「份额数据断了」；以 ETF 份额作协变量时 2026-05-01 不构成断点。
- AMAC《公开募集开放式证券投资基金流动性风险管理规定》第 27 条是独立上位规章，
  不因《准则第 2 号》修订失效，单一持有人占比超 20% 的提示**通道仍在**，只是字段为
  「投资者类别 / 持有份额 / 占比 / 份额变化 / 风险提示」，无账户名称，**确权能力归零**。
  「前十名持有人类别」是否普遍保留仍标「未能核实」。
- 2026-07 事件在严格匹配设定下无同段对照（指数同期续跌、无类似起点），
  结论应标「**不可检验**」而非「显著/不显著」；且一手公告未检索到，已排除出主样本。

## 十二、可证伪检验层（事件研究，新增）

系统新增 `src/ntm/statistics.py`、`event_study.py`、`events.py`、
`/api/event-study` 与 `scripts/fetch_public_index.py` /
`scripts/run_event_study.py`。**命题不是「证明 A 股走势与国家队资金高度相关」**，
而是可证伪的：「稳市事件后指数前瞻收益是否显著区别于非事件日基准」。

- **t=0 = 意图公开日（公告意图日）**，不是资金成交日。公告不含买入金额与成交时点；
  额度、中标、签约金额不能当「当日入市资金」主变量。按预先写死的编码规则，
  t=0 只取「信号 / 制度首次公开日」；**资金操作日与最终市场底日不作独立事件编码**，
  否则同一政策重复计数、并把结果变量当作原因。
- **份额跳升日降级为处理强度 / 中介变量**：它是逆周期反应的结果，且 L2 无法识别
  申购人，用它定义处理时点存在「用结果定义原因」的内生风险。可用「净申购额占规模
  比例」作连续处理强度，或以「公告日 + 后续是否有份额承接」分组。公告日测含信号 /
  预期渠道的总效应，份额跳升日测资金落地二阶效应，两者回答不同因果问题；
  短窗 T+5 的显著更可能来自信号渠道，不应解释成资金落地效果。
- **同一政策簇合并编码**，不得拆分虚增样本量（如 2024-09-24 三项同日动作）。
- **PIT 与符号约定**：**D = 信息首次公开日（事件锚 / 信号起点）**，
  **i0 = D+1 收盘（实际入场）**，两者不得混用；盘中 / 盘后公告不作区别，
  与项目 `entry_lag=1` 一致。D 当日入场仅进稳健性网格，属含前视偏差的上界口径
  （量化差 2.28pct）。非交易日事件映射到其后首个交易日；超出指数样本区间的事件直接排除。
- **分段理由**：S1/S2/S3 按**市场状态**分段（T+60 无条件均值 +0.18% / +4.94% / -4.51%，
  正占比 48.9% / 75.9% / 1.5%），指数日线序列本身口径连续，属状态漂移而非披露口径断裂；
  2024-08-19 与 2026-05-01 两个披露断点**仅约束协变量选择**（北向 / L1 确权），
  不影响纯收益基准。S3 大跌匹配池枯竭（≤-5% 仅 2~11 个、≤-8% 为 0），
  2026-07 事件须报「无可匹配对照」，不得硬凑。
- **下行风险结论**：未发现下行风险改善。分层匹配检验最大不利偏移 MAE：
  T+5 事件 -3.26% vs 对照 -2.24%（p=0.902）、T+20 -3.55% vs -2.77%（p=0.811）、
  T+60 -7.47% vs -5.14%（p=0.942），事件组左尾方向更厚。「压缩左尾」是
  待检验假设，不是托底机制的理论预设；一阶 / 二阶传导框架本身仍成立。
- **对照组**：非事件日同窗口收益，排除事件日 ±20 交易日，按 horizon 步长抽样
  以降低重叠窗口自相关；重叠无法完全消除，须在结论中披露。
- **判据**：置换检验 p 值 → 多 horizon Bonferroni 校正 → Bootstrap 置信区间 →
  改变入场滞后的稳健性网格。四项同时看，不挑显著的那一个报告。
- **不报同期相关系数作为结论**。央行《2024 年第四季度中国货币政策执行报告》
  专栏 2 明确两项资本市场工具「均内嵌逆周期调节属性，在股市超跌时工具使用量
  会比较大，股价上涨时自然减小」。因此同期相关度量的是**政策反应函数**而非
  **政策效果**，会被内生性压向 0 或负值；`statistics.lagged_correlation` 仅用于
  暴露「窗口自由度」陷阱，不作为结论指标。
- **事件清单只能人工确权**（`data/verified_policy_events.json`），
  `verified_by` 显式标注确权等级，绝不自动生成。该文件由研究总监依据团队成员
  回传的日期表整理落盘，**成员不直接维护**；`.gitignore` 已为它开例外以便版本化，
  其余 `data/` 运行期数据（行情 CSV、SQLite、检验结果 JSON）仍不入库。
- **确权通道限定**：单一持有人占比超 20% 的提示公告（《公开募集开放式证券投资基金
  流动性风险管理规定》第二十七条）只披露投资者**类别**、份额与占比，**不含账户名称**，
  只能作「机构集中度提示」对照变量，不是 L1 确权通道。旧半年度准则第 29 条要求的
  「前十名持有人名称」才是确权字段，2026 年新准则删掉的正是这一层。
- **窗口设定**：主检验 5 / 20 / 60 / 120 交易日，长尾补 250 交易日
  （2015 年政策底到市场底间隔 136 交易日，+120 覆盖不到）。窗口不足的事件自动跳过
  并标注，绝不截断窗口硬凑样本。
- **路径风险**：2024-09 事件 T+60 终点 +18.5%，但中途自 10-08 高点回撤 -24.9%。
  只看终点收益会严重低估风险，故同时报告窗口内峰谷回撤、相对入场价最深浮亏与
  跌破入场价比例（收盘价口径，浮亏为保守下界）。
- **行情底座**：`scripts/fetch_public_index.py` 抓东方财富公开不复权日 K
  （沪深300，2015-01-05 起）。该接口**不提供 ETF 总份额**，L2 缺口仍需
  Wind MCP（`NTM_WIND_MCP_KEY`）或其他已核验数据源，见第八节。
  演示数据（固定种子 20261109）只用于验证代码正确性，**不得用于统计结论**。
