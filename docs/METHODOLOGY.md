# 方法论：三层数据模型与边界

> 本文件是系统的设计依据。它解释了**为什么这个平台不提供「每天跟着国家队买什么」**，
> 以及在此约束下我们到底监控什么、如何标注可信度。

---

## 一、定位：从「跟单系统」改为「分层监控 + 带置信度的概率推断」

原需求是「每天跟着国家队操作 / 监控国家队资金判断是否进场」。经研判，
**这个目标的一半在公开数据下不成立**：

- 官方不逐笔披露国家队交易，盘中没有任何渠道能看到汇金下单；
- ETF 每日只公布总份额与申赎清单，**不公开申购人身份**；
- 保险、公募自营、券商自营、外资、国有资本都可能大额申购宽基 ETF；
- 上市公司十大流通股东 / ETF 持有人是**确权数据**，但滞后 1–2 个季度。

因此平台定位调整为：
> **用国家队资金相关公开信息判断「是否出现托底信号、敢不敢进场、进多少」（择时与仓位），
> 不用它判断「买哪只个股」（选股）。**

系统**不输出**买入/卖出/目标价/荐股措辞，只输出信号状态、置信度与局限说明。

## 二、三层数据模型

| 层级 | 名称 | 时效 | 可归因到主体 | 置信度 | 典型来源 |
|------|------|------|-------------|--------|---------|
| **L1** | 实测（季度确权） | 滞后 1–2 季 | ✅ 是 | high | 上市公司十大流通股东/十大股东、ETF 半年报与年报前十大持有人 |
| **L2** | 估算（T+1） | 盘后 T+1 | ❌ 否 | low | 宽基 ETF 每日**总份额**变动 × 当日净值 |
| **L3** | 代理 / 交叉验证 | T+0 ~ T+1 | ❌ 否 | medium | 央行/汇金/证监会/国资委/国新·诚通公告、互换便利、回购增持再贷款、融资余额、成交额 |

**铁律**

1. L2 永远 `attributable=False`，**不得**表述为「国家队买入 X 亿元」；
2. 基于 L2 的推断置信度上限为 `medium`；
3. 任何信号 `is_confirmed=False` 恒成立；
4. L1 的「名单新进/退出」不等于增减持。

**ETF 份额的正确用法**：份额增加 = 一级市场净申购；份额减少 = 净赎回。
二级市场成交额放大**不改变总份额**，只看放量会误判。
估算公式：`净申购额（亿元） = Σ(份额增量 × 当日净值) / 1e8`。

## 三、国家队主体清单（按披露账户名）

> 「国家队」是市场惯称，**无官方固定名单**。本系统显式枚举四组。

| 组 | 主体 | 备注 |
|----|------|------|
| 核心托底 | 中央汇金投资、中央汇金资产管理 | |
| 核心托底 | **中国证券金融股份有限公司** | = 证金公司 = 中证金公司，**同一实体，只计一次** |
| 核心托底 | 证金资管 / 中证金融资产管理计划（10 只） | 常出现在十大流通股东 |
| 扩围 | 中国国新（国新投资、国新宏盛） | 2024 后主力，增持央企/科技/ETF |
| 扩围 | 中国诚通（诚通金控、诚旸投资、诚通资本） | 同上 |
| 外汇局系 | 梧桐树投资平台、北京凤山投资、北京坤藤投资 | |
| 长线配置 | 全国社保基金及各组合、基本养老保险基金 | **单列，不与托底资金混算** |
| 排除 | 中国投资有限责任公司（中投） | 主权财富基金，主司境外投资；A 股主体为其子公司中央汇金 |

真正出现在十大流通股东名单里的是上表**具体账户名字符串**，因此必须建立
「别名 → 标准主体 ID」映射并按最长别名优先匹配（`src/ntm/entities.py`）。

## 四、术语表

| 术语 | 定义 |
|------|------|
| 净申购额 | ETF 份额增量 × 当日净值（亿元）。仅代表全市场一级市场净申购，无法识别申购人 |
| 名单进出 | 十大股东名单新进/退出，仅代表排名变化，不等于增持/减持 |
| 持股变动 | 经送转股/增发/回购复权调整后的持股数差额；被动变动不计入主动增减持 |
| PIT 时点 | `report_period`（季度标签）、`report_period_end`（期末 ISO 日）、`disclose_date`（实际披露日）、`effective_date`（= 披露日，策略最早可用日） |
| 托底信号 | 三重共振成立时的概率推断，永远 `is_confirmed=False` |
| 政策底 | 稳定市场力量开始加强的位置；**不等于市场底**，历史间隔 40 天至 6 个月 |

## 五、信号：三重共振

```
条件① 市场大跌      当日涨跌幅 ≤ -1.5%  或  近 5 日累计 ≤ -4.0%
条件② 宽基份额同步  同步净申购只数 ≥ 3  且  合计净申购额 ≥ 200 亿元
条件③ 官方公告      近 5 日存在增持/稳市类公告（is_supportive=True）

①∧②∧③ → POLICY_BOTTOM_PROBABLE  (confidence=medium)
仅 ②    → INFLOW_ONLY             (confidence=low)   只记「有大额增量资金承接」
仅 ③    → ANNOUNCEMENT_ONLY       (confidence=low)   公告表达意图，额度≠实际买入
其他    → NO_SIGNAL               (confidence=low)
```

阈值可通过环境变量调整（见 `.env.example`）。**三者缺一，绝不标记为国家队进场**。

每条信号附带 `attribution`（无法归因到具体主体）与 `caveat`：
政策底≠市场底、历史间隔 40 天至 6 个月、国家队入场可增强信心但不宜成为抄底理由、
系统不提供个股买卖建议。

## 六、四条硬性清洗规则

1. **名单进出 ≠ 增减持**：新进名单可能是首次买入，也可能只是排名上升进入前十；
   退出名单可能是减持，也可能是被其他股东挤出前十。二者均标记 `is_actionable=False`。
2. **复权**：`adjusted_prev = prev.shares × factor`；若复权后差额为 0，
   判为「被动变动（复权后无主动增减）」，不计入主动增减持。
3. **口径分离**：十大股东与十大流通股东禁止跨口径比较。
4. **PIT 防前视**：回测只用 `effective_date <= as_of` 的记录；
   信号盘后生成，最早入场时点为**下一交易日收盘**，不用当日收盘价成交。

---

## 七、回测约束

- 基准：同期指数买入持有；
- 考虑交易成本、涨跌停/停牌不可成交（当前 MVP 仅在说明层约束，未做撮合模拟）；
- 输出事件数、胜率、平均前瞻收益、最大回撤；
- **样本量警示**：国家队进场事件在历史上为个位数（2008/2015/2018/2024/2025/2026），
  任何统计结论都极易过拟合；政策底到市场底 40 天至 6 个月不等。

## 八、真实数据源接入核验清单（默认未完成）

`src/ntm/adapters/live.py` 只是骨架，`NTM_ENABLE_LIVE_ADAPTERS=0` 默认禁用。
接入前必须逐项确认并留档：

- [ ] 数据源的**授权与使用条款**（Wind / iFinD 需商业授权；公开页面需确认版权与 robots）
- [ ] 接口字段含义、更新频率、历史回溯范围、频控与反爬策略
- [ ] 只取 **ETF 总份额** 与 **净值**；禁用「主力资金流入」类指标
- [ ] 主体账户名的实际披露字符串清单，补全别名映射并补测试
- [ ] 季报/年报披露日抓取，保证 `disclose_date` 真实（不能用报告期末代替）
- [ ] 交易日历（节假日、临时休市），当前 `is_trading_day` 仅做周末粗判
- [ ] 失败重试、幂等去重、数据质量校验与缺失/异常值处理
- [ ] 归因边界：所有 L2 输出仍标注「不可归因」，接入真实数据也不改变这一事实

> **重要**：即使接入真实数据，「谁在申购 ETF」依然不可知。真实数据不会让
> `is_confirmed` 变成 True，只会让 L2 估算更准确。

## 九、合规与免责

- 凭据（webhook、SMTP）只从环境变量读取，不写入数据库、日志、报告或版本库；
- 默认演示数据为合成数据，页面与 API 强制显示 `is_demo` 警示；
- 所有输出标注「基于公开数据的概率推断，无法确权」；
- 系统不提供个股买卖建议、不构成投资建议或择时建议；
- 使用者需自行判断数据来源的合法合规性并承担决策风险。

## 十、已知限制

| 限制 | 影响 | 后续 |
|------|------|------|
| 演示数据为合成 | 不可用于实盘 | 按第八节接入真实源 |
| 交易日历仅判周末 | 节假日可能生成非交易日 | 接入交易所日历 |
| SQLite 单实例 | 不适合多实例并发写 | 数据量上来后迁 PostgreSQL/TimescaleDB |
| 未做撮合级回测 | 无滑点/涨跌停/停牌模拟 | 引入事件驱动回测框架 |
| 前端 CORS 为 `*` | 生产需收敛 | 部署时改为具体域名 |
| 信号样本极少 | 统计结论不稳定 | 只作参考，不作依据 |
